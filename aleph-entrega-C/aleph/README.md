# Aleph — Entrega C: shell, navegación y edición

Esta entrega inicia la capa de interfaz y experiencia del producto M0.

Incluye:
- app shell con sidebar, cabecera y contenido principal
- árbol de navegación jerárquico con expand/collapse
- vista de documento con tareas y bloques básicos
- panel de mapa acoplable
- selección y temas claros/oscuros
- estructura lista para conectar con A/B y continuar con editor real

## Cómo ejecutar

```powershell
cd aleph-entrega-C/aleph
npm install
npm run dev
```

## Scripts

- `npm run dev` — arranca Vite
- `npm run build` — compila la app
- `npm run typecheck` — comprueba tipos de TypeScript
